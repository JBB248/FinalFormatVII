HEY
Thanks for downloading Final Format VII!
This a formatting app that I made to print out a cover for Final Fantasy VII.

Using this app is as simple as finding a box art online, feeding it into this app by click "\[Select Box Art\]", 
choosing the box type (CD, PS2, Wii, etc.), and pressing export!
Everything should fit into A4, but I'm working on making more because I have not been 
anywhere that supports printing gloss paper at A4.
It will create an image automatically sized to the selected page size,
so that there's no concern of a printer incorrectly sizing the box art.

This app is free and open source on <a href="https://github.com/JBB248/FinalFormatVII">github</a>. 
Feel free to do whatever you want with it!
If you paid for this, you probably got scammed! Sorry!

Good websites I've found for downloading box arts are <a href="https://www.thecoverproject.net/">thecoverproject</a> (you definitely want an adblocker here),
and <a href="https://gamefaqs.gamespot.com/">gameFAQs</a>. At gameFAQS, search for the game you want, and then on its page click on media and then boxes.

NOTE: If you select to stretch the box art to the desired box size, it may recieve some degredation. Use it at your own risk!
The best strategy is to try and find a box art that's already about the same size, and use this to turn it into a printable page.
If you think that the box art is the correct size, try changing the output dpi.
The image's original dpi is shown in the log after loading the image.

If you want to make a box art with a reverse side for a transparent box (e.g Switch or PS3),
export the two separately, and make sure that they are exported at the same size.
FFVII centers box art on the output page, so as long as they are the same size, they will be aligned if printed front and back.

If you find that a cover is printing incorrectly sized, report it 
<a href="https://github.com/JBB248/FinalFormatVII/issues">here</a>
